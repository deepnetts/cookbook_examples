# Getting Started

This section takes you from a Java development environment to a verified Deep Netts installation. It is written for experienced Java developers who are new to Deep Netts and does not require previous Machine Learning experience.

Follow the pages in order:

## 1. Prerequisites

Confirm that Java 25 and Maven are installed and that Maven uses the correct JDK. You will also learn which runtime module Deep Netts 4 requires.

[Check the prerequisites](prerequisites.md)

## 2. Download

Get the Deep Netts distribution and license used by the course projects. You can read the hosted course without cloning its GitHub repository.

[Download Deep Netts](download.md)

## 3. Installation

Import the Deep Netts artifacts into your local Maven repository, add the dependencies to a Maven project, and configure the Java Vector API.

[Install and configure Deep Netts](installation.md)

## 4. Hello World

Clone and run a minimal Maven project that creates a Deep Netts neural network and performs a prediction. A successful run confirms that Java, Maven, the dependencies, license, and runtime configuration work together.

[Verify the setup with Hello World](hello-world.md)

```text
Prerequisites
     |
     v
Download
     |
     v
Installation
     |
     v
Hello World
```

After Hello World succeeds, continue to [Examples](../examples/index.md) and choose a complete regression or classification project.
