# Deep Netts Course

Learn the foundations of Machine Learning with Java and Deep Netts.

This course is intended for experienced Java developers who are new to Machine Learning. It introduces the concepts first, then connects them to compact Java examples that demonstrate the complete model-development workflow.

## How to use this course

The learning material is organized in three complementary levels:

```text
LEARN THE CONCEPT
        |
        v
BUILD THE PROGRAM STEP BY STEP
        |
        v
RUN THE COMPLETE PROJECT
```

### Learn the concept

The lectures explain the ideas behind Machine Learning, neural networks, the Deep Netts API, and model development. Start here if concepts such as features, targets, training, loss, and evaluation are new to you.

### Build the program step by step

Code-focused walkthroughs will progressively assemble each example, with short explanations between Java code sections.

### Run the complete project

The complete examples are standalone Maven projects containing the Java program, dataset, and detailed README:

- [Computer Hardware Performance Regression](https://github.com/deepnetts/cookbook-examples/tree/add-first-examples/examples/linear-regression)
- [Email Spam Classification](https://github.com/deepnetts/cookbook-examples/tree/add-first-examples/examples/spam-classification)

## Course path

1. [Machine Learning Basics](lectures/01-ml-basics.md)
2. [Neural Networks](lectures/02-neural-networks.md)
3. [Deep Netts API](lectures/03-deep-netts-api.md)
4. [Model Development](lectures/04-model-development.md)

The course will grow incrementally. Each topic will explain why a step is needed before presenting the corresponding Deep Netts code.
