Frequently Asked Questions
{% if current_section == 'get-started' %}
Which Java and Maven versions do I need?

The cookbook projects target Java 25 and use Maven. Confirm that both java -version and mvn -version report the expected JDK before running an example.

Why does Deep Netts need the Vector API module?

Deep Netts uses the JDK Vector API for optimized numerical operations. Add --add-modules jdk.incubator.vector to the runtime VM options.

Can I run the projects from NetBeans?

Yes. Open the example directory as a Maven project, select Java 25, add the Vector API module to VM options, and run its main class.

Where do I get Deep Netts?

Use the Free Download link in the header, then follow the Download and Installation sections on this page to add the required artifacts and license.

{% elif current_section == 'examples' %}
How do I run a complete example?

Each example is a standalone Maven project. Open its directory in NetBeans or run it with Maven using Java 25 and the Vector API module.

How can I test training with only one epoch?

For examples that expose the shared training property, add -Ddeepnetts.epochs=1 to the VM options.

Where are the datasets stored?

Small datasets are included under each project's src/main/resources/datasets directory. Large VGG weights are downloaded and cached separately.

Where are trained models saved?

Training examples create a local models directory and save the resulting .dnet model there.

{% elif current_section == 'developer-guide' %}
How does JSR 381 relate to Deep Netts?

JSR 381 defines standard Java Machine Learning contracts such as DataSet. Deep Netts provides concrete neural-network functionality and interoperates with those shared types.

How do I avoid preprocessing data leakage?

Split the dataset first, fit preprocessing only on the training set, and apply the fitted transformation to the test set and future inputs.

Should preprocessing be saved with the model?

Yes. A prediction must use the same transformation learned during training, so attach the fitted normalizer or scaler before saving the model.

When should I use the Developer Guide instead of Examples?

Use the Developer Guide for one focused API task. Use Examples when you need to see an entire workflow assembled into a runnable project.

{% elif current_section == 'course' %}
What is the recommended lesson order?

Start with Machine Learning Basics, continue with Neural Networks and the Deep Netts API, then finish with Model Development.

Do the lessons include runnable code?

The lessons explain concepts and compact code fragments. Use the Examples section for complete standalone Maven projects.

Should I learn regression or classification first?

Begin with regression to understand inputs, targets, training, and error. Then continue with binary and multiclass classification.

Where should I look up an unfamiliar term?

Use the Glossary for concise definitions and return to the relevant lesson for the full context.
