# NLP Examples

The current cookbook does not yet include a runnable raw-text Deep Netts NLP project.

Start with the [Natural Language Processing course lesson](../../lectures/05-natural-language-processing.md) for tokenization, vocabularies, numerical text representations, classification, sequence context, and evaluation guidance.

The [Email Spam Detection walkthrough](../classification/email-spam-detection.md) demonstrates a related binary-classification workflow using prepared numerical email features. It does not tokenize or model raw email text.
